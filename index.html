ETAPE 1 Creer le Google Sheet + Apps Script
1
Creer un nouveau Google Sheet
Allez sur sheets.google.com → Nouveau classeur → Nommez-le "Lola Formation - BDD"
2
Creer les 3 feuilles
En bas du classeur, creez 3 onglets nommes exactement : Formations   Abandons   Actions
3
Ouvrir l'editeur Apps Script
Dans le Sheet : menu Extensions → Apps Script. Supprimez le code existant et collez le code ci-dessous.
4
Code Apps Script a copier
const SHEET_ID = SpreadsheetApp.getActiveSpreadsheet().getId();

function doGet(e) {
  return handleRequest(e);
}
function doPost(e) {
  return handleRequest(e);
}

function handleRequest(e) {
  var params = e.parameter || {};
  var postData = {};
  try {
    if (e.postData && e.postData.contents) {
      postData = JSON.parse(e.postData.contents);
    }
  } catch(err) {}

  var action = params.action || postData.action;
  var sheet = params.sheet || postData.sheet;
  var data = postData.data;

  var output;
  try {
    if (action === 'ping') {
      output = { ok: true, msg: 'Lola Formation BDD connectee' };
    } else if (action === 'read') {
      output = { ok: true, data: readSheet(sheet) };
    } else if (action === 'write') {
      writeSheet(sheet, data);
      output = { ok: true };
    } else {
      output = { ok: false, msg: 'Action inconnue: ' + action };
    }
  } catch(err) {
    output = { ok: false, msg: err.toString() };
  }

  return ContentService
    .createTextOutput(JSON.stringify(output))
    .setMimeType(ContentService.MimeType.JSON);
}

function readSheet(name) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName(name);
  if (!sh) return [];
  var rows = sh.getDataRange().getValues();
  if (rows.length < 2) return [];
  var headers = rows[0];
  return rows.slice(1).map(function(row) {
    var obj = {};
    headers.forEach(function(h, i) { obj[h] = row[i]; });
    return obj;
  });
}

function writeSheet(name, data) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName(name);
  if (!sh) sh = ss.insertSheet(name);
  sh.clearContents();
  if (!data || !data.length) return;
  var headers = Object.keys(data[0]);
  var rows = data.map(function(obj) {
    return headers.map(function(h) { return obj[h] !== undefined ? obj[h] : ''; });
  });
  sh.getRange(1, 1, 1, headers.length).setValues([headers]);
  if (rows.length) {
    sh.getRange(2, 1, rows.length, headers.length).setValues(rows);
  }
}
5
Deployer comme application web
Dans Apps Script : Deployer → Nouveau deploiement → Type : Application web
• Executer en tant que : Moi
• Qui peut acceder : Tout le monde
• Cliquez Deployer → autorisez → copiez l'URL generee
6
Coller l'URL dans les Parametres
Allez dans Parametres → Google Sheets, collez l'URL Apps Script, cliquez Tester la connexion.
ETAPE 2 Heberger sur GitHub Pages
1
Creer un compte GitHub (si necessaire)
github.com/signup — compte gratuit, 2 minutes.
2
Creer un nouveau repository
github.com/new
• Nom : lola-formation
• Visibilite : Public (requis pour GitHub Pages gratuit)
• Cochez Add a README file → Create repository
3
Uploader le fichier HTML
Dans le repository : Add file → Upload files
Glissez gestion-formation-lola-v6.html, renommez-le index.html avant l'upload (ou renommez apres upload).
Cliquez Commit changes.
4
Activer GitHub Pages
Dans le repository : Settings → Pages (menu gauche)
• Source : Deploy from a branch
• Branch : main • Dossier : / (root)
• Save → attendre ~2 minutes
5
Votre URL est prete
Votre outil est accessible sur :
https://[votre-pseudo].github.io/lola-formation/

Pour mettre a jour l'outil : retournez dans le repository, cliquez sur index.html → icone crayon → modifiez ou re-uploadez → Commit. Mis en ligne en 2 minutes.
Important : le repository doit rester Public pour GitHub Pages gratuit. Vos donnees de formation sont dans Google Sheets (non visible sur GitHub). Seul le code HTML est public — ne mettez jamais votre cle Brevo dans le fichier HTML.
RECAP Architecture finale
Navigateur → charge index.html depuis GitHub Pages
Config (cle Brevo, templates) → stockee dans localStorage du navigateur
Donnees (formations, abandons) → lues/ecrites dans Google Sheets via Apps Script
Mails → envoyes directement par Brevo API depuis le navigateur
